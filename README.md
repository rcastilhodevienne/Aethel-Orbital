# 🌌 Aethel: Orbital

Um jogo de quebra-cabeça móvel focado em física, lógica e relaxamento, com design visual de luxo, projetado para dispositivos móveis.

🕹️ **[Clique para Jogar](https://seu-usuario.github.io/aethel-orbital/)** *(Adicione seu link de deployment aqui!)*

## ✨ Características do Jogo
* **Altamente viciante (Gamificação natural):** Enigmas baseados em alinhamento físico e ótico.
* **Leve e Ultra Fluido:** Construído em HTML5 nativo com Phaser 3, pesando menos de 1MB.
* **Estilo Luxuoso:** Paletas de cor profundas, metais polidos e cristais mágicos inspirados em jogos premium de quebra-cabeça 3D.
* **Totalmente Responsivo:** Suporta qualquer tamanho de tela e rotação mobile.

## 🚀 Tecnologias
* HTML5
* JavaScript (Phaser 3 Game Engine)
* CSS Moderno
